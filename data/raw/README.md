# Исходные данные

> **Файл `train.csv` (~38 МБ) не хранится в репозитории** из-за размера.
> Его необходимо скачать самостоятельно перед запуском проекта.

---

## Что должно лежать в этой папке

    data/raw/
    └── train.csv    # ~38 МБ, датасет Rossmann Store Sales

---

## Откуда скачать

**Датасет:** Rossmann Store Sales (Kaggle)

Ссылка: https://www.kaggle.com/competitions/rossmann-store-sales/data

Нужен бесплатный аккаунт Kaggle. После скачивания архива извлеките `train.csv` и положите его в эту папку.

Если работаете в Google Colab — скачивать локально не обязательно, bootstrap-ячейка в ноутбуках делает это автоматически через `gdown` (см. `notebooks/00_prepare_data.ipynb`).

---

## Структура `train.csv`

| Колонка          | Описание                                 |
|------------------|------------------------------------------|
| `Store`          | ID магазина                              |
| `DayOfWeek`      | День недели (1–7)                        |
| `Date`           | Дата наблюдения                          |
| `Sales`          | Выручка за день                          |
| `Customers`      | Количество клиентов за день              |
| `Open`           | Магазин открыт (1) или закрыт (0)        |
| `Promo`          | Промо-акция (1) или нет (0)              |
| `StateHoliday`   | Государственный праздник (0 / a / b / c) |
| `SchoolHoliday`  | Школьные каникулы (0/1)                  |

---

## Как подготовить данные

После того как `train.csv` окажется в этой папке, выполните из корня проекта:

    python -m src.create_dataset

Скрипт подготовит `data/processed/restaurant_daily.csv`. Подробности — в основном `README.md`.

---

## Почему данных нет в репозитории

Файл весит ~38 МБ, а репозиторий не должен содержать датасеты >10 МБ. Вместо этого в репо хранится скрипт подготовки (`src/create_dataset.py`) и эта инструкция — стандартная практика в ML-проектах.
